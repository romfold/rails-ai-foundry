# Packages

Use `foundry:context NAME` for new contexts under packs/. Preserve existing roots via upstream packs.yml and an explicit --path option. package.yml exclusively owns topology and public boundaries; adjacent foundry.yml owns profile, namespace, patterns and capabilities. Foundry never loads application packages.

See [native contexts](native-contexts.md), [native AI](native-ai.md) and [the implementation program](implementation-program.md) for detailed contracts and delivery status.
