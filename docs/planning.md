# Planning

Read installed context configuration and the selected specification workflow. Requirements describe behavior, plans propose implementation and ADRs explain rationale. Do not duplicate the package inventory. `foundry plan refactor --context=NAME --profile=PROFILE` produces a read-only source assessment; it does not convert code, data or specs. Implement authorized changes with behavioral tests and ordinary Rails loading verification.

See [native contexts](native-contexts.md), [native AI](native-ai.md) and [the implementation program](implementation-program.md) for detailed contracts and delivery status.
