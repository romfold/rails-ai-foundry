# Promotion

Automatic 0.1 profile promotion is removed. Use `foundry plan refactor --context=NAME --profile=PROFILE` for read-only evidence, then review and implement namespace, configuration and code changes with tests. Changing profile alone neither moves files nor converts data or event streams.

See [native contexts](native-contexts.md), [native AI](native-ai.md) and [the implementation program](implementation-program.md) for detailed contracts and delivery status.
