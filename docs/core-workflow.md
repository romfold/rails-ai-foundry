# Core workflow

Start with behavior and context ownership using the installed foundry-plan and foundry-add-feature skills. Follow the [first-feature tutorial](first-feature.md) for a complete two-context Rails feature and [packs usage](packs.md) for direct package operations. Foundry is built on Rails, packs, packs-rails and Packwerk.

Install the eight skills with `bin/rails generate foundry:skills --target=agents` (also claude or cursor). Read application-local workflow selection first. Implement native application code, using the small Foundry generators only when a scaffold helps. Run structural checks, isolated Packwerk checks and owning behavioral tests. Reconcile the selected workflow after those pass.

See [native contexts](native-contexts.md), [native AI](native-ai.md) and the [next program](next-program.md) for contracts and pending scope.
