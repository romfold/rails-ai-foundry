# Skill-led development program

Foundry is a development-time conventions and skills kit built on Rails, packs, packs-rails and Packwerk, with native RubyLLM conventions. Applications own execution. This program follows the completed 0.2–1.0 delivery ledger and records the user's subsequent decisions; it does not reopen that reset.
