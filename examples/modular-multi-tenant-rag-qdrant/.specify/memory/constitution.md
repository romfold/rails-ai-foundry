# Vector knowledge principles

PostgreSQL is authoritative; Qdrant is rebuildable. Tenant/version filters and fresh document checks precede citations.
Use an application-owned integration boundary and no Foundry execution code. Normal providers are offline.
Architecture belongs in [config](../../config/foundry.yml) and [knowledge](../../packs/knowledge/foundry.yml).
Maintain living requirements and reconcile plan/tasks when behavior changes.
