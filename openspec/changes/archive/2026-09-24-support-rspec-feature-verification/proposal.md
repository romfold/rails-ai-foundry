## Why

Installed verification currently requires Minitest. RSpec applications need equally explicit execution evidence without pretending that example outcomes count expectations.

## What Changes

Add explicit framework selection, native RSpec evidence and independently bundled installed HTTP/browser acceptance. Preserve Minitest defaults, conservative skill upgrades and current production dependencies.

## Capabilities

### New Capabilities
- `rspec-feature-verification`: RSpec feature verification.

### Modified Capabilities
None.

## Impact

Existing skills, installed acceptance, explicit packaging and documentation. No new Foundry runtime, configuration, catalog application, agent trial or publication. Final verification uses the existing release-candidate change.
