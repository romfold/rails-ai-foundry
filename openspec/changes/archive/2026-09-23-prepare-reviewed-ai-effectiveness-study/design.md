## Context

A fresh installed journey needs an independently graded feature task before any new agent effectiveness claim.

## Goals / Non-Goals

Implement the user-approved skill-led AI delivery program in three bounded changes. Preserve eight skills, twelve apps, current native execution, historical results and unfinished study/hosted gates.

## Decisions

- Prepare a separate two-group feature study using existing Le Mans and independent grading.
- Freeze inputs and validate valid/faulty controls offline.
- Document six serial trials with twenty-minute limits; require separate execution authorization.

## Risks / Trade-offs

Offline acceptance establishes reproducibility, not user usability or agent improvement. Archive resources must work without the checkout. Privacy checks are heuristic and must never print values. Acceptance remains pending until actual tests pass.

## Migration Plan

Preserve application-owned files and receipts. No business-data migration or automatic catalog overwrite. Record verified evidence before archiving.
