## Why

All four profile runtimes now have local verification. Developers still need a safe promotion workflow, complete installed guidance, and proof that the built archive delivers these capabilities without repository-only resources.

## What Changes

- Add previewable, staged profile promotion with explicit checked activation and event-sourcing cutover documentation.
- Install profile-promotion and event-workflow skills with bundled references and registry-generated convention tables.
- Generate application guidance and test every profile using the installed gem in minimal hosts with network requests blocked.
- Reconcile roadmap, research traceability, and compatibility evidence with delivered behavior.

## Capabilities

### New Capabilities
- `profile-delivery`: Safe profile transitions, generated guidance, and packaged four-profile acceptance.

### Modified Capabilities
- `foundry-skills`: Bundle supporting resources and add promotion and event workflow skills.

## Impact

Profile generator, conservative staging and activation, skill installer and catalog, host guidance, archive acceptance, and documentation. Existing v1 behavior is preserved; adoption, examples, AI expansion, and publishing remain deferred.
