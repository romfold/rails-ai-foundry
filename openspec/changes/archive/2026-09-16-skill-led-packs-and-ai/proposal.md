## Why

Foundry already delegates package discovery, operations and Rails loading upstream, but its onboarding and skills still make generators the primary workflow. The approved next program makes application behavior and ownership the starting point, with executable guidance and stronger AI evidence.

## What Changes

- Name Rails, packs, packs-rails and Packwerk as the foundations; document direct upstream commands and their side effects.
- Reconcile research and replace generator-led planning with eight richer skills and a packaged, replayed two-context first-feature tutorial.
- **BREAKING (unpublished candidate)**: default new agent prompts to the owning pack; preserve complete existing receipts and document explicit relocation.
- Add opt-in boot-free prompt contracts and focused source diagnostics with separate severity and certainty.
- Extend the existing pgvector RAG flagship with Neighbor, stale-embedding protection, retrieval evidence and adaptation guidance.
- Add independent experimental FlowNodes branching and Langchainrb adoption recipes with offline acceptance.

## Capabilities

### New Capabilities
- `prompt-contracts`: explicit boot-free validation of application-owned prompt contracts.
- `experimental-ai-recipes`: independently bundled FlowNodes and Langchainrb examples and evidence limits.

### Modified Capabilities
- `foundry-skills`: skill-led planning, direct packs guidance and progressive RAG adaptation.
- `packaged-core-workflow`: distributable first-feature tutorial replayed from the installed archive.
- `agent-generation`: pack-local prompts with explicit application-owned lookup and preservation.
- `native-source-diagnostics`: focused architecture rules, severity and certainty.
- `rag-pgvector-flagship`: Neighbor retrieval, revision safety and instrumentation.
- `stable-contracts`: optional prompt command/report surface and unpublished prompt-placement change.

## Impact

README, roadmap, packaged guides and skills; agent templates and ownership handling; source/prompt checks and JSON Schemas; archive and AI acceptance; the existing RAG app and two new experimental recipe bundles. Core Ruby/Rails floors, eight skill names, twelve-app catalog and existing locks stay authoritative. No packs wrapper, capability generator, prompt runtime or automatic architecture planner is introduced. Hosted CI, paid evaluations, real agent benchmarks, full ROM/RES/Elasticsearch/AI composition and publication remain separate scopes.
