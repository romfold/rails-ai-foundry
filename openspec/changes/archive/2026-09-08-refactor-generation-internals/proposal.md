## Why

Generation internals duplicate safe-write orchestration and occupy the public runtime namespace. Consolidation and explicit subsystem namespaces make maintenance safer without changing consumer behavior.

## What Changes

- Consolidate scaffold execution, rollback details, ancestor creation, manifest publication and structural guards.
- Rename internal implementations into Generation, Setup and Promotion without aliases.
- Preserve public constants, generator paths, generated bytes, safety behavior and optional loading.
- Load checkers only when needed.

## Capabilities

### New Capabilities
None.

### Modified Capabilities
None. This is an internal refactor; skip_specs is explicit.

## Impact

Internal Ruby requires and repository callers change. Existing application manifests, runtime API, generated resources and commands remain unchanged. Version 0.1.0, Ruby >=3.3, railties >=7.1 and MIT remain.
