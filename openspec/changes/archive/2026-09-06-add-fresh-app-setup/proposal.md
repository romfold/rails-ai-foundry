## Why

Developers currently assemble installation, skills, and loading by hand. A packaged Rails template should compose the verified core while preserving Rails defaults.

## What Changes

- Add a local template command and conservative setup generator with preview.
- Exercise actual Rails application creation from the installed archive.
- Keep ordinary installation and optional capabilities unchanged.

## Capabilities

### New Capabilities
- `fresh-app-setup`: Packaged template and repeatable complete setup.

### Modified Capabilities
None.

## Impact

Gem executable, Rails template, setup composition, installed guidance, and archive acceptance. No publishing or example work.
