## MODIFIED Requirements

### Requirement: Explicit capability status

Project guidance SHALL distinguish implemented behavior, proposed changes, and roadmap ideas. Research input SHALL remain contextual material and SHALL NOT automatically become project instructions or implemented requirements.

#### Scenario: Inspect framework availability

- **WHEN** a contributor reads the current README and roadmap after executable-package implementation
- **THEN** they see that contributor tooling, safe installation, package generation, opt-in Rails loading, and structural checks are available
- **AND** AI integrations, dependency/privacy enforcement, and other future capabilities remain identified as planned work
- **AND** research-derived ideas are not presented as implemented without verification
