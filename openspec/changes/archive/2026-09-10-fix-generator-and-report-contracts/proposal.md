## Why

Review reproduced locale-dependent JSON reporting failures, competing component/agent constants, and unloadable acronym namespaces. These defects undermine the current 1.0 report and generator contracts despite passing ordinary core tests.

## What Changes

- Normalize upstream report text to valid UTF-8 while preserving exit status and accepted debt.
- Check component and agent/tool/schema ownership together before generation or preview.
- Automatically generate application-owned Rails namespace inflections with independent receipts and collision checks.
- Verify locale, ownership, eager-loading and upgrade behavior with regressions and installed consumers.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `native-boundary-verification`: locale-independent upstream report text.
- `context-intent`: shared generated-constant ownership and automatic namespace inflections.
- `agent-generation`: conflicts with component-owned constants and safe inflection installation.
- `stable-contracts`: report encoding and inflection ownership/repair guarantees.

## Impact

Development-time report capture, generators, receipts, tests and upgrade documentation. No Foundry production runtime, version/schema bump, provider traffic or unrelated capability work. The hosted release-verification gate remains separate.
