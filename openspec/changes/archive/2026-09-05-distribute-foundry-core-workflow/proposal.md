## Why

The gem must deliver its reusable skills and prove a complete workflow outside the checkout. OpenSpec contributor skills and example applications do not supply that product contract.

## What Changes

- Package four self-contained, versioned Foundry skills and install them conservatively into consuming applications.
- Add an offline archive-installation acceptance suite using an independent minimal Rails host.
- Document the complete non-AI workflow and record local verification evidence.

## Capabilities

### New Capabilities

- `foundry-skills`: Versioned skill bundles and safe application-local installation.
- `packaged-core-workflow`: Installed-archive acceptance independent of examples and checkout code.

### Modified Capabilities

None.

## Impact

Adds root `skills/` product resources, `foundry:skills [--target=agents|claude]`, packaged core documentation, and `rake test:package`. Depends on the operation and boundary capabilities in `complete-core-generators-and-boundaries`. No AI, example, or publication work.
