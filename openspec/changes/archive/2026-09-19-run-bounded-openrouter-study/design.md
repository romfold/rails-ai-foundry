# Design

Use pinned native miniswen with openrouter/openai/gpt-5.6-luna#medium and OpenAI-only routing without fallback. The host makes provider calls; candidate and grader containers remain offline. Freeze the current source, selected tasks, dependency/image receipts and command order in an external study directory.

The ten attempts are hello-world; boundary-extraction and stale-embedding across rails/packs/foundry; ar-tenant-isolation; aj-enqueue-after-commit; ft-comment-reaction-live-echo. Smoke has $0.25, three minutes and 15 steps. Other attempts have $0.75, ten minutes and 50 steps. All cap response output at 4096 and shell commands at 60 seconds. Shared allocation is $7; user-approved key limit is $20 lifetime without reset. This explicit amendment changes only the key limit; the $7 study stopping threshold and original $10 overall budget remain unchanged.

prepare-study creates inputs and a command sheet, never agents. study-preflight checks frozen inputs, expected order, unused attempt outputs, prior native/independent results and OpenRouter metadata; it records sanitized receipts and reserves the attempt once. Authentication, quota, unknown accounting, insufficient allowance and unavailable routing stop progress. Per-request overshoot remains explicit. No resets, retries or replacement agents.

Existing replay keeps control behavior by default. A prepared study workspace opts into live semantics, preserving unscored limit outcomes and separate independent diagnostics. study-report uses the fixed attempt manifest, never oracle/nop expectations, and reports native/independent grades, tokens, costs, provider deltas, incomplete and unstarted attempts. Original and derived evidence remain create-only.

A missing host key blocks paid execution, not offline implementation. Provide terminal commands for the key-owning shell and preserve a truthful unstarted report if execution cannot begin. Do not claim successful execution or archive unperformed work.
