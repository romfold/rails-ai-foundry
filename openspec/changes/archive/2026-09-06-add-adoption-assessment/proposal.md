## Why

Existing Rails applications need a source-only inventory before developers choose package ownership. Strict checks alone do not explain gradual extraction.

## What Changes

- Add manifest-optional CLI assessment with structured findings and explicit limitations.
- Deliver a seventh skill and bundled manual extraction guidance.

## Capabilities

### New Capabilities
- `adoption-assessment`: Read-only inventory and dependency assessment.

### Modified Capabilities
- `foundry-skills`: Include the adoption skill and resources.

## Impact

CLI, shared static source inputs, adoption analysis, skill catalog, and isolated legacy fixtures. No automatic moves or data conversion.
