## Why

The existing optional agent generator emits legacy Ruby roots that profiled packages reject. Align the existing scaffold with canonical adapters so consumers can use it without weakening architecture checks.

## What Changes

- Generate manifest-v2 AI classes in registry-defined external adapters with ordinary namespaces and mirrored tests.
- Preserve manifest-v1 paths, interfaces, and receipts; reject legacy scaffolds in profiled packages with manual reconciliation guidance.
- Verify composition, public entry points, result mapping, safe repeats, and loading from an installed archive without provider requests.
- Update existing shipped guidance and correct stale Ruby-floor statements. Keep RubyLLM optional and its supported version range unchanged.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `agent-generation`: Profile-aware placement and conservative layout reconciliation.
- `rubyllm-integration`: Align the documented Ruby floor with the existing gem floor.

## Impact

Agent templates and installer, optional AI tests and archive acceptance, existing skills and bundled references, compatibility evidence. No new AI runtime, persistence, RAG, streaming, examples, publishing, or support desk work.
